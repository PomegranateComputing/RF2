# Dépendances et corpus

Le roman et son univers appartiennent à leur auteur. Ce pack contient de nouvelles géométries et des matériaux de construction créés pour son projet. Le roman, les anciennes maps et les assets RF2 d'origine ne sont pas inclus.

Le ZIP livré ne redistribue ni UZDoom ni Freedoom. La préparation les télécharge depuis leurs distributions officielles, avec leurs notices :

- UZDoom 5.0.1 : GPL-3.0-or-later ; https://github.com/UZDoom/UZDoom
- Freedoom 0.13.0 : licence BSD modifiée, notices fournies dans la distribution ; https://github.com/freedoom/freedoom
- ZDBSP : outil de construction utilisé, non inclus ; https://github.com/rheit/zdbsp

Le code de construction des maps utilise Python standard. La reconstruction des PNG avec `build_art.py` requiert Pillow. Les fichiers PNG sont déjà fournis : Pillow n'est pas nécessaire pour jouer ou modifier un WAD.
