# ASTRA — RF01 P0 PROPS

Batch : `RF01_P0_PROPS`.

Créer un petit kit qui donne une identité physique à Sainte-Anne.

Priorité :

- lit/infrastructure de chambre ;
- radiateur ;
- table/chaise institutionnelle ;
- chariot linge ;
- armoire/casier ;
- luminaire ;
- panneau/support de signalétique SANS texte baked ;
- équipement de consultations générique cohérent avec le canon ;
- banc/objet de cour ;
- éléments chapelle simples ;
- portes/encadrements distinctifs si utiles.

Éviter les objets décoratifs impossibles à lire ou à placer.

Chaque prop doit avoir dimensions/échelle et type d'utilisation : sprite, voxel/model, geometry reference.

Target suggéré : `sprites/props/saint_anne/` ou `models/props/saint_anne/`.
