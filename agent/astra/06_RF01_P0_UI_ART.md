# ASTRA — RF01 P0 UI ART

Batch : `RF01_P0_UI`.

Créer le shell visuel des menus/HUD, sans implémenter les menus et sans baked text.

## Livrer

- fond principal ou traitement de fond ;
- plaque/panneau menu ;
- séparateurs ;
- focus/selection frame ;
- cadres HUD discrets ;
- icônes santé/armure/ammo/clé si elles améliorent réellement la lecture ;
- éléments décoratifs de transition/credits si utiles.

## Style

Sévère, matériel, noir/anthracite/acier/bordeaux profond si cohérent. Pas de translucide SaaS, pas de néon cyberpunk générique, pas de faux HUD militaire surchargé.

Tout texte final sera rendu par le moteur. Ne grave pas « NEW GAME » ou autres labels dans les images.

Exporter au moins une planche 16:9 montrant composition 1080p/1440p sans imposer un layout impossible à adapter en 4K.

Target suggéré : `ui/art/` et `graphics/`.
