# ASTRA — RF01 P0 MATERIALS

Batch : `RF01_P0_MATERIALS`.

Créer 8–12 familles cohérentes pour Sainte-Anne, pas 80 textures sans emploi.

Familles prioritaires :

- plâtre/peinture institutionnelle ;
- carrelage mural ;
- sol carrelé ou pierre ;
- béton/pierre de cour ;
- métal peint ;
- bois verni/usé ;
- verre/fenêtre ;
- textile/rideau ;
- surfaces de service/lingerie ;
- éléments chapelle/consultations si visibles.

## Pour chaque famille

- base propre ;
- 1–3 variantes utiles (usure, humidité, reprise, salissure localisée) ;
- tileable lorsque le matériau le demande ;
- échelle physique documentée ;
- pas de texte généré ;
- pas de grunge uniforme.

Résolution source : 1024 ou 2048 selon besoin. Runtime peut être inférieur si Fable le juge préférable.

Si tu fournis normal/roughness/specular, garde-les comme compléments documentés ; ne rends pas l'intégration dépendante d'un shader non confirmé.

Manifest target sous `textures/saint_anne/` et `flats/saint_anne/`.
