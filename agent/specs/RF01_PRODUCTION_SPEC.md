# RF01 — Sainte-Anne / spécification de production

## Fonction

RF01 est le standard de qualité de la campagne. Il doit prouver que RF2 peut être produit vite sans sentir le générateur.

## Éléments de canon spatial à exploiter

- Chambre
- Admissions
- Cour des hommes
- Pavillon est
- Lingerie
- Galerie nord
- Registres
- Chapelle vide
- Consultations
- Porche

## Transformation attendue

Le blockout V1 n'est qu'un graphe de départ.

Créer une architecture institutionnelle crédible : pièces secondaires, encadrements, services, fenêtres, vues sur cour, escaliers, différences de hauteur, passages techniques, circulation principale et circulation du personnel.

Éviter la succession grosse boîte -> corridor -> grosse boîte.

## Flow cible

1. réveil/entrée dans la chambre ;
2. première lecture du lieu et des contrôles ;
3. admissions / premier verrou contextuel ;
4. cour comme landmark ;
5. boucle pavillon/lingerie/galerie ;
6. registres comme objectif ou révélation ;
7. chapelle comme branche significative, pas distributeur de clé ;
8. retour transformé vers les consultations/admissions ;
9. montée de pression ;
10. porche / climax / sortie.

Le flow peut être amélioré si le canon local le justifie.

## Cibles

- 15–25 min première découverte mesurée ;
- 10–14 séquences spatiales distinctes ;
- 2 différences de hauteur significatives au minimum ;
- 2 boucles/raccourcis ;
- 5–7 rencontres authored ;
- 1 respiration forte ;
- 1–3 secrets si naturels ;
- aucune progression reposant sur une mécanique de debug ;
- deux parcours complets après les dernières modifications.

## Gameplay

Le premier niveau ne doit pas exposer tout l'arsenal. Priorité au FAL et éventuellement une deuxième arme seulement si elle enrichit réellement les rencontres.

Trois familles ennemies maximum pour RF01, chacune lisible par silhouette et comportement.

## Art

Réalisme stylisé matériel : institution ancienne, métal peint, pierre/plâtre, carrelage, bois, textile, verre, usure localisée. Pas de photoréalisme incohérent mélangé à des sprites grossiers.

## Son

Le niveau doit posséder sa propre présence acoustique : ventilation, portes, pas, réverbérations, extérieur/cour, combat. Pas de tapis sonore générique continu qui masque tout.
