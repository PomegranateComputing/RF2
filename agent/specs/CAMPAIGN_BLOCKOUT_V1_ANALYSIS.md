# Analyse des 23 blockouts V1

## Ce qui est conservé

- 23 identités de niveau et ordre de campagne ;
- ancres narratives ;
- lieux nommés ;
- UDMF éditable ;
- certaines connexions, landmarks et grands espaces ;
- MAPINFO de campagne comme point de départ.

## Ce qui n'est PAS considéré final

- géométrie orthogonale générée ;
- corridor standard de 3 cellules / 192 unités ;
- hauteurs répétitives ;
- piliers/caisses/racks automatiques ;
- badge bleu systématique ;
- deux secrets systématiques ;
- exit au nord ;
- population d'ennemis automatique ;
- matériaux de blockout.

## Répétitions topologiques à casser

Groupes partageant une ossature très proche ou identique :

- RF04 / RF07 / RF08 / RF14 / RF18 / RF23 ;
- RF01 / RF06 / RF16 ;
- RF03 / RF05 / RF13 ;
- RF09 / RF15 ;
- RF11 / RF19.

Une transformation doit donner à chaque lieu sa propre grammaire spatiale.

## Priorités qualitatives

RF01 Sainte-Anne : vertical slice et standard de production.

RF02 Paris : alternance intérieur/cour/rue, rues plus organiques, échelle crédible.

RF07 Jerma : verticalité, façade maritime, vues traversantes, hall et ailes réellement distincts.

RF08 Aile des chambres : couloir hôtelier crédible, chambres, services, ruptures et raccourcis ; pas de grandes boîtes successives.

RF09 Piscine : exploiter le bassin comme landmark, niveaux, filtration, sous-gradins et sightlines.

RF13 Waukegan : motel, parking, coursives, chambres, arrière industriel, lumière du lac.

RF18 Gennevilliers : échelle industrielle, quais, rails, hangars, canal et circulation logistique.

RF20 Copie de secours : casser la grille de « base de données » par mezzanines, faux planchers, câblage, salles serveurs et interruptions de visibilité.

RF22 Destinataire présent : commencer rationnel puis rendre les connexions progressivement impossibles / contradictoires.

RF23 Épilogue : volontairement calme, spatialement lisible et distinct de RF01 malgré le thème clinique.

## Doctrine

Le layout V1 encode une intention de circulation, pas une architecture sacrée.

Fable peut déplacer, fusionner, subdiviser, verticaliser et reconstruire tant que l'identité narrative et le flow global restent lisibles.
