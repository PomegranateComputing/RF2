## Défauts (captures `dist/arsenal/RF2_ARSENAL_ESSAI_20260929_1545/preuves/captures_1532/1920x1080/`, nom = tic)

1. **Recul quasi nul** : FIRE/RECOIL/RECOVERY déplacent le centre de 1 à 2 px. Attendu : relevé du canon et poussée
   de la main de tir (un .357 dans une main avec soutien), du même ordre que le Browning accepté. Tics `0153`, `0155`, `0159`.
2. **Extraction sans geste** : `reload_eject` = 2 images, 4 tics ; la main gauche reste écartée, les étuis disparaissent.
   Attendu : pouce ou main gauche sur la tige d'extracteur, poussée, étuis qui sortent, relâchement. Tics `0193`, `0195`.
3. **Étuis tirés = cartouches intactes** barillet ouvert : livrer `rig_layers.chambers_fired` (même forme que
   `chambers`) : amorce percutée, embouchure sombre, pas de balle. Tic `0191`.
4. **Chambre 4, étape de main 1** : seule la pointe de la cartouche dépasse du bas du cadre. La cartouche doit être
   tenue entièrement dans le cadre ou sortir franchement. Tic `0227`.
