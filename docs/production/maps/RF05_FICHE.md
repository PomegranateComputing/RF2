## Adaptation ludique (déclarée)

- Galeries techniques sous le parc (câbles, pompes du Niagara, transformateur) où se trouvent les pièces de la
  réparation : invention de liaison, cohérente avec « le moteur battait quelque part sous le parc » (l. 529).
- Rencontres : le personnel de Sainte-Anne descend après Viktor (galeries), puis tient le parc rallumé. La jeune
  femme, le couple, les danseurs des miroirs ne sont jamais des cibles ; les voix du couloir (l. 721–727) relèvent de RF06.

## Ressources demandées

La jeune femme sans valise, pieds nus (F05-01) ; les danseurs et le couple dans les miroirs (F05-02) ; moteur, roue et
courroie (modèle, animation), levier trois positions, coffret NODE 0 (fermé / ouvert, diodes vertes / rouges),
tableaux de marbre et cadrans, train de trois voitures ; sons : battement, arrêt, redémarrage, courroie renforcée,
diodes, ventilateurs, frein automatique, ampoules. Détails : demande RF04-RF05 dans l'espace actif d'Astra.
